# 06 — 燈箱內左右鍵切換圖片

**What to build:** 使用者瀏覽一篇有多張圖片的文章、開啟燈箱時，可以直接用左右鍵切換瀏覽同一篇文章的上一張/下一張圖片，不用點小按鈕。

**Blocked by:** 01 — 文章可上傳/顯示超過 3 張圖片；02 — 桌面鍵盤導覽（不含燈箱）

**Status:** ready-for-agent

- [ ] 燈箱開啟時，按左右鍵會切換到目前文章圖片清單中的上一張/下一張圖片
- [ ] 燈箱開啟期間，左右鍵原本「切換文章列表頁」的行為暫時讓位給切換圖片
- [ ] 按 Esc 關閉燈箱後，左右鍵自動恢復成切換文章列表頁的行為
- [ ] 只有一張圖片的文章開啟燈箱時，左右鍵沒有可切換的圖片，不會出錯或有異常行為

# 02 — 桌面鍵盤導覽（不含燈箱）

**What to build:** 桌面雙欄版面下，使用者可以用鍵盤快捷鍵瀏覽文章列表、切換文章、開新文章表單、關閉彈窗/燈箱，不需要用滑鼠操作這些常見動作。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 在桌面雙欄版面，按上鍵切換到目前選定文章的上一篇（較新），按下鍵切換到下一篇（較舊）
- [ ] 在目前已載入頁次的邊界（最舊的一篇）按下鍵時，操作停住不動，不會觸發翻頁
- [ ] 按 Ctrl+K 直接開啟發新文章的表單
- [ ] 按 Esc 關閉目前開啟的彈窗或燈箱（看板列表彈窗、跳頁彈窗、既有的圖片燈箱）
- [ ] 按左右鍵切換文章列表的頁次（沿用既有的跳頁機制）
- [ ] 使用者的 focus 在輸入框（標題、內容、留言等文字輸入區）時，上述快捷鍵（Esc 除外）不會被觸發，不影響正常打字
- [ ] 這組快捷鍵只在桌面雙欄版面生效，手機版操作方式不受影響

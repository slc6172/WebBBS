# 03 — 拖曳/貼上上傳圖片

**What to build:** 使用者在發文（桌面/手機）、編輯文章時，除了點檔案選取，也可以把圖片檔案拖曳進上傳區、或直接在編輯畫面貼上剪貼簿裡的圖片。

**Blocked by:** 01 — 文章可上傳/顯示超過 3 張圖片

**Status:** ready-for-agent

- [ ] 桌面發文、手機發文、編輯文章三處的圖片上傳區，都支援把檔案從桌面拖曳進來加入圖片清單
- [ ] 三處的文字輸入區，都支援直接貼上剪貼簿裡的圖片，貼上後自動加入圖片清單
- [ ] 拖曳/貼上加入的圖片，跟原本點檔案選取加入的圖片一樣，會經過相同的格式/大小驗證，不合法的圖片會被擋下並提示錯誤
- [ ] 拖曳/貼上加入圖片後，仍然遵守 99 張數量上限與 30MB 總量上限，超過時提示明確錯誤

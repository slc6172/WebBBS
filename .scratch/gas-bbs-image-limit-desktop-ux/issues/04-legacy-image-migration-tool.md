# 04 — 舊資料遷移工具

**What to build:** 提供一支管理者可以手動執行一次的工具，把既有文章的圖片資料轉換成新的儲存格式，讓舊文章在新程式碼上線後依然能正確顯示圖片。

**Blocked by:** 01 — 文章可上傳/顯示超過 3 張圖片

**Status:** ready-for-agent

- [ ] 工具會掃過全部既有文章，把舊格式的圖片欄位資料轉換成新格式的圖片清單欄位
- [ ] 已經是新格式的文章會被跳過，不會被重複處理或覆蓋
- [ ] 完全沒有圖片的文章會被跳過，並計入統計
- [ ] 工具可以重複執行多次，結果穩定不會損毀資料（idempotent）
- [ ] 執行完畢後，執行紀錄會印出清楚的統計數字：轉換筆數、已是新格式跳過筆數、空白跳過筆數
- [ ] 工具只修改圖片相關欄位，不會動到文章的其他欄位或其他工作表
- [ ] 工具不會刪除或清空舊格式的圖片欄位，只負責寫入新欄位
- [ ] 部署文件中清楚寫明必須先執行這支工具、確認統計結果無誤，才能部署會讀寫新圖片欄位格式的程式碼

# 05 — LINE 彙整發文放寬圖片門檻

**What to build:** LINE 群組聊天彙整發文時，不會再因為累積到 3 張圖片就被迫提前發文，累積的圖片也不會被悄悄截斷丟棄。

**Blocked by:** 01 — 文章可上傳/顯示超過 3 張圖片

**Status:** ready-for-agent

- [ ] 群組聊天累積圖片數量達到 99 張（而不是原本的 3 張）才會因為圖片數量觸發彙整發文
- [ ] 群組聊天累積文字量達到既有門檻時，依然照原本的邏輯觸發彙整發文（這條件不變）
- [ ] 彙整發文時，累積的全部圖片都會完整出現在最終文章裡，不會因為超過某個數量而被截斷丟棄
- [ ] 既有測試更新以反映新的門檻數值，並補上「累積圖片數超過 3 張但少於新門檻時不觸發彙整」的案例
- [ ] 補上「輸入超過 3 個圖片網址時全部原封不動傳遞、不截斷」的回歸測試

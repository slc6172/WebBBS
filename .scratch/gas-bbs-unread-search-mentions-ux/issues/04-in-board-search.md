# 04 — 看板內搜尋

**What to build:** 文章列表上方常駐一個搜尋輸入框，使用者輸入關鍵字、按 Enter 或點搜尋按鈕，就能在目前所在看板內找到標題、內文、或任一則回覆內容包含這個關鍵字的文章；命中回覆時直接導到該回覆所屬的文章。搜尋範圍優先比對前端已載入的資料（即時、零額外試算表讀取），使用者可以主動觸發擴大範圍到「更早、尚未載入」的文章再一併搜尋。搜尋不會跨看板，也因此不會搜到使用者沒有讀取權限的其他看板內容。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 文章列表上方（跟現有分頁 bar 同一區域）新增搜尋輸入框與觸發按鈕
- [ ] 按 Enter 或點按鈕才觸發搜尋，不做即時邊打邊搜
- [ ] 搜尋比對範圍：`boardBulkCache[currentBoardId]` 裡已載入的每篇文章標題、內文，以及該文章底下每則回覆的內容
- [ ] 命中回覆時，搜尋結果導到該回覆所屬的文章（不做「跳到特定回覆」的錨點定位）
- [ ] 若目前看板 `hasMore`（還有更早分頁尚未載入），提供明確的操作讓使用者主動擴大搜尋範圍，重用既有 `loadMoreArticles(boardId)` 分頁機制載入後一併納入比對；不自動觸發
- [ ] 搜尋範圍固定為目前所在看板，不提供跨看板搜尋選項
- [ ] 純前端邏輯，沒有對應的 Node 測試 seam；`MANUAL_VERIFICATION.md` 新增這張票的真人環境驗收項目（標題命中、內文命中、回覆命中並正確導到所屬文章、擴大範圍後能搜到更早文章、確認搜尋不出現其他看板內容）
